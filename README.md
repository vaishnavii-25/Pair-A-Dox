# Pair-A-Dox

## Overview

Pair-A-Dox is a full-stack memory card matching game built using React and Express. The objective is to match all pairs of cards in the shortest possible time. Player scores are stored in a MongoDB database, allowing completed games to be recorded and displayed on a leaderboard.

---

## Features

* Classic memory card matching gameplay
* Randomized card placement for each game
* Real-time game timer
* Highscore leaderboard
* Persistent score storage using MongoDB
* Responsive user interface

---

---


## How to Play

1. Start a new game.
2. Flip two cards at a time.
3. Matching cards remain face up.
4. Non-matching cards are flipped back over.
5. Continue until all pairs have been matched.
6. Complete the game as quickly as possible to achieve a better score.
